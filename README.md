# Bruce

**Systems builder | Infrastructure | Automation | Technical operations**

San Diego, California

I build practical systems that have to work outside a demo: virtualized infrastructure, self-hosted services, networks, AI automation, internal tools, websites, and the physical projects around them.

My favorite work starts with, "This should exist," and ends with something deployed, tested, documented, and maintainable. I am especially interested in infrastructure, systems integration, technical operations, automation, and AI-enabled workflow roles.

## What I work on

- Proxmox and Linux infrastructure
- Self-hosted services, networking, and secure remote access
- Local-first AI agents and owner-controlled automation
- Internal tools that turn scattered business data into usable workflows
- Static sites and lightweight web applications
- Hardware, electrical, carpentry, and custom fabrication projects

I use AI-assisted development heavily, but generated code is only part of the job. I define the requirements, design the architecture, manage deployment, test real behavior, and verify the result.
